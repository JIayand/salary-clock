# 薪资时钟操作手册

本文档是仓库内可独立阅读的用户操作手册。应用内「设置 → 操作手册」提供可搜索的逐项说明；两者涉及功能、设置路径、默认值和操作方式时必须保持一致。设置页左侧只显示分类名称，右侧不重复展示小字副标题；复杂计算、开关影响和使用限制通过对应项目旁的「？」查看。

## 1. 首次使用

1. 打开薪资时钟，在「薪资与家庭」填写月薪。
2. 选择每周工作日，至少选择一个工作日。
3. 直接键盘输入上班和下班时间。小时范围为 0–23，分钟范围为 0–59。
4. 如果有固定午休，打开「启用午休」后再输入午休开始和结束时间；没有固定午休则保持关闭。
5. 所有设置自动保存，无需单独点击保存。

## 2. 设置分类

- **桌面显示：** 主显示内容、金额和百分比精度、进度条、统计项目、悬浮窗布局、窗口层级和数字动画。
- **薪资与家庭：** 本人和家庭成员薪资、每周工作制度、上下班时间、午休及税后工资估算。
- **摸鱼设置：** 摸鱼扣除规则、每日摸鱼估算、摸鱼记录和摸鱼统计。
- **提醒与目标：** 愿望清单和下班提醒。
- **通用设置：** 界面语言、主题、背景透明度和隐私模式。
- **操作手册 / 关于：** 搜索功能说明、查看版本和更新日志。关于页面的更新日志按大版本分组、小版本逐项选择，默认显示当前安装版本；每条变更独立编号展示。

主显示内容原先位于薪资计算区域，现已统一移动到「桌面显示 → 主显示」。

## 3. 悬浮窗与桌面组件

- macOS 悬浮窗显示实时收入和工作进度；鼠标移入可展开更多统计，紧凑模式可减少占用空间。
- WidgetKit 提供小、中、大、超大桌面组件。超大组件可展示家庭成员收入总览；数据按分钟级时间线更新，刷新时机由 macOS 管理，不保证秒级实时刷新。
- 新增功能应同时在悬浮窗和适用的桌面组件中提供；如受 WidgetKit 限制不能完全一致，应在 README 和应用内手册说明限制。
- 主题、隐私、进度样式和显示开关应在支持的展示端保持一致。

## 4. 薪资、金额和数字输入

- 月薪、年终奖、社保/公积金基数与比例、专项附加扣除、愿望目标金额和已存金额均可直接键盘输入。
- 所有金额和统计数字使用千位分隔，例如 `12,345.67`；时钟、日期和时长保持原格式。
- 金额小数位、百分比小数位可分别设置。
- 休息估算分钟数可以直接输入；步进器仅作为辅助调整方式。

## 5. 工作时间和午休

进入「薪资与家庭 → 工作时间」：

- 上班和下班时间均可直接输入小时、分钟，不需要依赖下拉选择器。
- 「启用午休」默认关闭。关闭时不显示午休时间字段，计薪时间按完整上下班区间计算。
- 开启后才显示午休开始和结束字段，午休区间从有效计薪工时中扣除。
- 家庭成员可分别配置自己的工作时间和午休开关。
- 当前不支持跨午夜班次。

## 6. 下班与加班记录

到达本人计划下班时间后，悬浮窗提供两个操作：

- **下班：** 结束当天工作，不再累计加班时间。
- **继续加班：** 从点击时刻开始累计加班；结束时点击「结束加班」，保存本次实际起止时间。
- 加班状态和历史起止时间保存在本机。当前版本已为后续周、月、年统计与报表导出保留记录，尚未提供报表导出界面。
- 计划下班时间本身不会自动算作加班，避免下班后忘记关闭窗口导致时长虚增。

## 7. 下班提醒

进入「提醒与目标 → 下班提醒」：

- 打开提醒开关。
- 小时和分钟可直接键盘输入，分别限制在 0–23 和 0–59。
- 点击「发送测试通知」检查 macOS 通知权限和投递状态。
- 提醒时间独立于上下班时间，修改工作时间不会自动修改提醒时间。应用会检查系统是否保留定时通知，并在重新激活时重新配置。

## 8. 摸鱼设置与摸鱼估算

进入「摸鱼设置」，先开启「启用摸鱼统计」：

- 可按上厕所、玩手机、喝水/休息、吃饭和其他类型设置每日估算分钟数。
- 每项分钟数支持直接键盘输入（0–240 分钟），步进器作为辅助。
- 可以在悬浮窗实时开始/结束休息，也可以手动补录开始和结束日期时间。
- 手动补录日期时间采用可编辑字段；结束时间必须晚于开始时间、不能晚于当前时间，并且不能与已有记录重叠。
- 今日概况分开展示实际工作时长、摸鱼时长、实际记录和系统估算，并提供本周、本月累计及实际工作时薪。
- 摸鱼时长按每种类型分别比较实际记录与每日估算，取较大值，不重复相加；只有开启扣除的类型才会影响实际工作时长。

## 9. 进度条样式

进入「桌面显示」选择进度条样式：

- **圆角实心：** 单色胶囊形填充，简洁直观。
- **渐变：** 渐变填充，带柔和光晕和进度端点，视觉更突出。
- **分段：** 将进度拆成多个独立区块，便于快速判断完成比例。
- **细线：** 极细轨道配合进度端点，尽量减少视觉占用。

选择会自动保存，并同步到悬浮窗、家庭成员进度、愿望清单进度和桌面 Widget。

## 10. 家庭成员

在「薪资与家庭 → 家庭成员」添加或删除成员。切换顶部人员标签后，可分别设置每个人的月薪、工作日、上下班时间、午休、税后参数。桌面悬浮窗和 Widget 应按各成员配置显示各自收入和进度。

## 11. 隐私、外观和统计

- 隐私模式可遮挡收入金额；进度百分比和时间仍可见。
- 主题、背景透明度、数字动画和统计项目可在设置中调整。
- 进度条样式通过统一设置选择，所有适用展示端保持一致。
- 设置修改自动保存。

## 12. 版本与问题排查

- 在「关于」查看当前版本和更新日志。
- 本地设置保存在设备上；升级前建议按需备份。
- 如果悬浮窗和 Widget 展示不一致，先确认两端已刷新，再检查是否有对应功能开关或系统 WidgetKit 刷新限制。
- 项目构建和开发规范见仓库根目录 `AGENTS.md` 与 `README.md`。

---

**维护要求：** 每次修改用户可见功能时，同步更新本手册、应用内操作手册、README 和 CHANGELOG。不得只更新其中一份。

## 关于页面与更新日志

打开设置左侧的「关于」，页面会默认显示当前安装版本的更新内容。更新日志按大版本归组，展开大版本后选择具体小版本即可查看；版本数量增加时，可在列表中滚动查找。各版本更新内容使用编号条目展示。

设置页面中的计算口径、开关影响和使用限制统一通过对应项目旁的「？」查看，主界面不再重复展示解释性小字。
